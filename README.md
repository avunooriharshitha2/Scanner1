# Simple Vulnerability Scanner

## Objective
To develop a basic Python-based scanner that checks a computer for open ports and identifies commonly used network services.

## Key Features
- Scans selected ports on localhost.
- Detects open and closed ports.
- Displays common services.
- Provides a basic security assessment.
- Uses Python socket programming.

## How It Works
1. The program starts the scanner.
2. It checks predefined ports on localhost.
3. It attempts to connect to each port.
4. Open ports are displayed with their common services.
5. The scan results help understand basic network security.

## Skills Involved
- Python programming
- Socket programming
- Network security
- Basic vulnerability assessment

## Learning Outcomes
- Understand basic port scanning.
- Learn Python socket programming.
- Understand network ports and services.
- Learn basic vulnerability assessment.
